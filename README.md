# Sanjeev C - Professional Portfolio Website

Modern, responsive portfolio website for **Sanjeev C** (B.Tech Textile Technology candidate at PSG College of Technology, Industrial Engineer, and Sustainability Researcher).

Built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## 🌟 Highlights

- **Dual Domain Focus**: Textile Technology & Industrial Engineering.
- **Experience Timeline**: Onsite industrial internships at **Aditya Birla Lifestyle Brands Limited** and **Coimbatore Polytex (Premier Mills)**.
- **Featured Research**: Bio-composite packaging using waste human hair fibers, 64-participant Doctor Towels case study, and salt-reed grass sustainable home textiles.
- **Verified Credentials**: Six Sigma Yellow Belt, Lean Six Sigma White Belt, and Kanban certifications.
- **Printable Resume**: 1-click print or Save-as-PDF modal with clean print typography.
- **Theme Support**: Seamless Dark and Light mode toggle with local storage persistence.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
